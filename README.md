# SHAMUS // REIMAGINED

## Visual Alpha v0.3 — gameplay hotfix & controller navigation

Offline 2D arcade fan-remake in the approved **CGA Reborn × Tech-Noir** style.

### Fixes in v0.3
- Enemy bullets no longer damage other robots. Missed player shots must never clear a room.
- The +200 room-clear bonus is only awarded when every spawned robot is killed by player projectiles.
- Enemy spawn locations are validated against the **current** room's collision walls (not the previous room).
- Shots use swept segment hit-testing, improving hit detection during frame drops.
- Controller menu: D-pad/left stick changes **Novice / Advanced**, **A / Start** begins/restarts.
- **Start** pauses/resumes once per press in-game. Keyboard arrows + Enter also work in menu.
- Controller A used to start no longer fires stray shots until the button is released.
- Four independently designed high-contrast illustrated SVG sprites replace the simple character sketches, with procedural fallback rendering.

### Installing on Android
Download the v0.3 APK from the successful [GitHub Actions run](https://github.com/UncleDozer/Shamus/actions), or use the APK provided in the conversation. It is a standalone, offline Android app. No browser application is required; the engine renders inside the APK's Android WebView. Android 8+; Android 16 target. Landscape and GameSir supported by native key forwarding.

**Important:** Debug APK signing keys are generated by GitHub runners. If Android refuses to update over v0.2, uninstall the previous test version first, then install v0.3. A fixed release signing key will be needed later for seamless upgrades.

### Controls
| Context | Controls |
| --- | --- |
| Menu | D-pad or left analog stick selects difficulty; A or Start begins the game |
| Keyboard menu | Arrow keys to choose difficulty; Enter or Space starts |
| Gameplay | Left stick or D-pad to move in eight directions |
| Fire | Hold A / RB / RT and a movement direction (aim without moving) |
| Pause | Start, keyboard P, Esc or on-screen Pause |
| Touchscreen | Left virtual joystick and right FIRE button |
